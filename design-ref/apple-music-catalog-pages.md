### 主页的编排规律

- 前 9 段是**固定骨架**：專屬精選推薦 → 最近播放 → (一条曲风) → (一条种子) → 為你製作的歌單 →
  為你精選的電台 → 找到迎合心情的內容 → 為你推薦最新作品 → 推薦歌單。
- 第 10 段往后是**长尾**：曲风 / 年代 / 「<艺人>的樂迷還喜歡」/「更多類似作品 + 种子」交替排，
  **段标题就是推荐的种子或维度本身**，不是固定栏目名。
- 长尾里绝大多数是**方卡**，内容以**专辑**为主、夹编辑歌单；只有 1/5/23 三段是海报卡。
- 电台只出现在 1 / 6 / 7 三段，且**电台卡没有链接，点了直接播**。

## 5. 复刻 Amber 时要注意的几件事

1. **段标题不是固定栏目名**。主页长尾的段名是推荐种子（歌名 / 歌单名 / 艺人名 / 曲风 / 年代），
   「更多類似作品」这种关系词放在**小字 headline** 里，大字是种子名本身。
2. **專屬精選推薦不是一堆歌单**。它是电台 + 专辑 + 歌单混排，靠每张卡的 eyebrow
   （專屬推薦 / 最新發行 / <艺人>參與作品 / 心情歌單推薦）说明推荐理由。
   而且是**逐张换类型**、不是按类型分组：实测顺序 电台 → 艺人电台 → 专辑 → 心情电台 →
   歌单 → 专辑 → 电台 → 歌单。Amber 照这个配方摆（`CatalogSlotResult.topPicks`），
   头两张一定是**个人电台**（网易云用雷达歌单、QQ 用「猜你喜欢」「随心听」）。
   「<艺人>參與作品 → <艺人>和類似藝人」那种艺人电台两家都还交不出来，位置让给别的类型。
   **音源的推荐流歌单不进这一段**（用户 2026-09-03 定的）：QQ 的 PlaylistSquare、
   网易云的 personalized/playlist 那批是「不听绝对后悔！抖音近期洗脑热歌」这类 UGC 标题，
   跟这一段的编辑气质不搭；它们照旧出现在「为你制作的歌单」「歌单已更新」等段里。
3. **电台卡的两种长相**：主页的电台走方卡（图下两行）；广播页的电台台名烘在图里、图下还有两行。
4. **方卡里装的主要是专辑**，不是歌单。长尾的曲风/年代货架尤其如此。
5. 曲目行只在新发现出现两次（新歌精选、正在流行中），一次 4 行多列。
